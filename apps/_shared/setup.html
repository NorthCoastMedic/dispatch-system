准备安装…

PWA（添加到手机主屏幕）装完后再看，不影响本次安装

  • 必须用 HTTPS 域名访问。Service Worker 与「添加到主屏幕」只在 HTTPS（或 localhost）下生效；用 http://内网IP:端口 打开不会生效。
  • 反代部署要打开信任代理。把根目录 .env 里的 TRUST_PROXY 改为 1，否则登录 Cookie 在反向代理后面可能异常。
  • 图标只需一张 512×512 PNG。放到 apps/_shared/public/pwa/icon-source.png（或在「系统设置 → PWA」上传），重启后自动生成 192 / 512 / 180 等尺寸。
  • 手机安装。安卓 Chrome 打开会提示安装；苹果 Safari 点「分享 → 添加到主屏幕」。全站只有一个 App，入口是门户。
  • 离线能力。断网或弱网时，RMS 响应终端仍可切换状态、上报事件，操作先存在本机，联网后自动上传；其余模块需要联网。
