# dispatch-system

## 项目简介

本系统是一套针对赛事与急救场景的实时后端支持系统，通过支持MQTT协议的软硬件来实现终端设备定位数据接入，结合GCJ-02坐标系进行实时位置处理，并提供包括设备监控、赛道轨迹计算、活动节点提醒、人员类型区分、人员在线状态在内的计算机辅助调度系统(CAD)
